# 🔱 LEVIATHAN GHOST-VAULT v21.0
**Advanced Steganography with Plausible Deniability Architecture**

LEVIATHAN is a high-security vault system designed to embed encrypted data within carrier images while mimicking authentic mobile device metadata.

## 🛡️ Key Security Features
* **Duo-Vault Architecture:** Implements "Double Bottom" encryption, allowing users to reveal decoy data under duress while keeping primary secrets hidden.
* **Ghost Metadata Protocol:** Automatically generates authentic iPhone 15 Pro EXIF tags to bypass forensic heuristic scans.
* **Military-Grade Encryption:** AES-256 (CBC Mode) with SHA-256 key stretching and Zlib pre-compression.
* **Pattern Masking:** Injects ICC profile mimicry to hide binary trailers from standard image viewers.
